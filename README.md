# Schleifen-Werkstatt

Browser-Lernumgebung zum Programmieren mit Python und gturtle (wie in TigerJython): Schleifen, Zählvariable, while-Schleifen und Variablen. Mit Aufgaben in drei Niveaustufen, Tipps, Code-Puzzles, Vorhersage-Aufgaben, Variablen-Speicher und Punktesystem.

Die ganze App steckt in einer einzigen Datei: `index.html`. Sie braucht keinen Server und keine Installation.

## Im Browser öffnen

Über GitHub Pages: https://smimueller.github.io/schleifenwerkstatt/

Fortschritt und Punkte werden im Browser des jeweiligen Geräts gespeichert (localStorage). Es werden keine Daten an einen Server geschickt.

## Aktualisieren

Neue Version von `index.html` hochladen oder committen. GitHub Pages veröffentlicht sie nach ein bis zwei Minuten.
